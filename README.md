# TerraLoop AI

TerraLoop AI is an Earth Forward hackathon project that turns a household waste list into a prioritized circular-economy action plan: repair, reuse, donate, recycle, or dispose safely.

## Why it matters
Most recycling tools answer only one question: “which bin?” TerraLoop instead tries to keep products in use for longer, reduce landfill waste, and explain the impact of each action.

## Hackathon build scope
Built during NextStep Hacks 2026. This repository was empty before the hackathon implementation began.

## Features
- Local AI-style decision engine with transparent rules
- Waste-stream classification
- Circular action ranking: repair > reuse/donate > recycle > disposal
- Estimated landfill diversion and CO2e savings
- Personalized action checklist
- Offline-friendly, zero-account demo
- No paid APIs or secrets required

## Run
Open `index.html` in a browser, or serve the folder with any static server.

## Tech
Vanilla HTML/CSS/JavaScript so the full decision logic is inspectable by judges and works offline.
